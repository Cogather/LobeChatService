# 1. **接口文档（API 文档）**

### 1.1. 接口地址

```
POST /api/mask_sensitive
```

### 1.2. 请求参数

| 参数名        | 类型     | 是否必填 | 说明                      |
| ---------- | ------ | ---- | ----------------------- |
| message    | string | 是    | 需要脱敏的内容（可为代码、配置、SQL等文本） |
| repo\_name | string | 是    | 代码仓库名称（目前未用，可留空或随意填写）   |

#### 示例请求

```json
{
  "message": "my password is 123456. Welcome to OpenAI. URI: https://user:pass@domain.com?apikey=aaa123",
  "repo_name": "test_repo"
}
```

---

### 1.3. 返回参数

| 参数名             | 类型     | 说明     |
| --------------- | ------ | ------ |
| masked\_message | string | 已脱敏的内容 |

#### 示例返回

```json
{
  "masked_message": "my password is ******. Welcome to MockCompany. URI: https://******:******@domain.com?apikey=******"
}
```

---

### 1.4. 返回码

| 状态码 | 说明   |
| --- | ---- |
| 200 | 成功   |
| 400 | 参数错误 |
| 500 | 服务错误 |

---

# 2. **设计文档**

## 2.1. 项目背景和目标

本接口用于对外部或内部传入的敏感内容（如代码片段、配置、SQL、日志等）进行自动脱敏。
**目标：**

* 对于敏感信息（如密码、token、api\_key、私钥、公司名、工号、账号、密码、URI敏感字段等）进行统一正则脱敏处理。
* 后续支持针对不同repo的定制化敏感词（本版暂不实现，预留repo\_name参数）。

---

## 2.2. 整体流程

```mermaid
graph TD
A[收到请求: message, repo_name] --> B[通用正则批量脱敏]
B --> C[预留: 按repo查找扩展敏感词(本版暂不实现)]
C --> D[返回脱敏结果]
```

**详细步骤：**

1. **收到请求**：获取请求体中的`message`和`repo_name`参数。
2. **通用脱敏处理**：对message执行统一的正则匹配和替换，包括但不限于密码、token、api\_key、私钥、公司名、工号、账号密码、URI等。
3. **（预留）repo定制化扩展**：按repo\_name查询数据库，获取定制化敏感词表，继续处理（本版仅注释，未实现）。
4. **输出结果**：返回脱敏后的字符串masked\_message。

* **正则表达式维护**：所有脱敏逻辑均在masking.py文件，便于团队统一维护和扩展。
