# LobeChatService 设计文档

## 项目概述

LobeChatService 是一个基于 Flask 的企业级聊天服务平台，集成了多个 AI 生态系统（OpenAI、DeepSeek、Google、Anthropic、Kimi 等），为用户提供智能对话服务。本项目采用微服务架构设计，具备完整的用户权限管理、Token管理、会话管理等功能。

## 🏗️ 核心功能模块

### 1. 用户管理模块
- **用户信息管理**：支持6级部门层级结构
- **权限控制**：基于角色的访问控制（RBAC）
- **用户组管理**：灵活的用户组织架构

### 2. 会话管理模块
- **会话创建**：支持自定义人设和话题
- **会话恢复**：完整的会话历史记录
- **多会话管理**：并发会话支持

### 3. AI生态系统集成
- **OpenAI**：GPT系列模型集成
- **DeepSeek**：深度求索模型支持
- **Google**：Gemini等模型接入
- **Anthropic**：Claude模型集成
- **Kimi**：国产模型支持

### 4. Token管理系统
- **余额管理**：用户Token余额查询和管理
- **申请流程**：完整的Token申请审批流程
- **使用追踪**：详细的使用记录和统计

### 5. 安全防护
- **权限验证**：多层次权限验证机制
- **内容过滤**：敏感信息掩码处理
- **访问控制**：IP白名单和访问限制

## 🚀 快速开始

### 环境要求
- Python 3.9+
- MySQL 8.0+
- Redis 7.0+
- Docker (可选)

### 本地开发部署

```bash
# 1. 克隆代码
git clone <repository-url>
cd LobeChatService

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 文件配置数据库等信息

# 4. 初始化数据库
python manage.py db upgrade

# 5. 启动服务
python run.py
```

### Docker部署

```bash
# 使用Docker Compose启动
docker-compose up -d

# 查看服务状态
docker-compose ps
```
