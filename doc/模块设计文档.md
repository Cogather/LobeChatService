# LobeChatService 模块设计文档

## 1. 模块概览

LobeChatService采用模块化设计，将不同功能划分为独立的模块，便于开发、测试和维护。每个模块都有明确的职责边界和接口定义。

### 1.1 模块分层

```plantuml
@startuml 模块分层
package "表现层 (Presentation Layer)" {
  [Flask路由]
  [蓝图管理]
  [请求处理]
}

package "业务层 (Business Layer)" {
  [用户管理]
  [会话管理] 
  [消息处理]
  [AI模型集成]
  [Token管理]
  [权限控制]
}

package "数据层 (Data Layer)" {
  [SQLAlchemy ORM]
  [数据模型]
  [缓存管理]
}

package "基础设施层 (Infrastructure Layer)" {
  [配置管理]
  [日志系统]
  [工具函数]
  [外部API]
}

[Flask路由] --> [业务层]
[业务层] --> [SQLAlchemy ORM]
[业务层] --> [基础设施层]
@enduml
```

### 2.4 AI模型集成模块

**模块路径**：`routes/open_ai_ecosystem_api/`

**核心功能**：
- 统一的AI模型调用接口

- 流式响应处理

**模型适配器设计**：
```plantuml
@startuml AI模型适配器
abstract class AIModelAdapter {
  +call_model(request_data)
  +handle_stream_response()
  +process_error(error)
}

class OpenAIAdapter {
  +call_model(request_data)
  +handle_stream_response()
}

class DeepSeekAdapter {
  +call_model(request_data)
  +handle_stream_response()
}

class GoogleAdapter {
  +call_model(request_data)
  +handle_stream_response()
}

class AnthropicAdapter {
  +call_model(request_data)
  +handle_stream_response()
}

  +call_model(request_data)
  +handle_stream_response()
}

AIModelAdapter <|-- OpenAIAdapter
AIModelAdapter <|-- DeepSeekAdapter
AIModelAdapter <|-- GoogleAdapter
AIModelAdapter <|-- AnthropicAdapter
AIModelAdapter <|-- KimiAdapter
@enduml
```

**统一调用流程**：
```plantuml
@startuml AI模型调用流程
participant "客户端" as Client
participant "路由层" as Route
participant "权限验证" as Auth
participant "模型适配器" as Adapter
participant "外部AI API" as ExternalAPI

Client -> Route: AI模型调用请求
Route -> Auth: 验证用户权限
Auth -> Route: 权限验证结果

alt 权限验证通过
  Route -> Adapter: 调用模型适配器
  Adapter -> ExternalAPI: 发送API请求
  ExternalAPI -> Adapter: 返回响应(流式/非流式)
  Adapter -> Route: 处理响应数据
  Route -> Client: 返回最终结果
else 权限验证失败
  Route -> Client: 返回权限错误
end
@enduml
```

    """数据模型基类"""
    
    def save(self):
        """保存模型实例"""
        db.session.add(self)
        db.session.commit()
        
    def delete(self):
        """删除模型实例"""
        db.session.delete(self)
        db.session.commit()
        
    def to_dict(self):
        """转换为字典格式"""
        return {c.name: getattr(self, c.name) for c in self.__table__.columns}
